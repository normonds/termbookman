# AI Agent Project Summary: rust-dashboard (termbookman)

## 1. Project Overview
`rust-dashboard` is a high-performance terminal dashboard built with Rust and the Ratatui TUI framework. It provides a split-pane environment with a live PTY terminal, a command sidebar, and integrated GitHub Gist management.

## 2. Technical Stack & Architecture
- **TUI Framework:** `ratatui` + `crossterm`.
- **Terminal Emulator:** 
    - **PTY:** `portable-pty` runs the underlying shell.
    - **Parser:** Uses a **locally patched `vt100` crate** (`patch/vt100/`) for Alternate Character Set (ACS) support (box-drawing characters).
- **Core Loop:** Asynchronous event handling using `tokio` and `mpsc` channels for PTY data, UI ticks, and user input.
- **Persistence:** Configuration and GitHub tokens stored in `~/.config/termbookman/config.toml`.

## 3. Key Components & Files
- `src/main.rs`: Entry point and primary application logic (UI rendering, click handling, state management).
- `patch/vt100/src/perform.rs`: Custom implementation of ACS mapping logic.
- `commands.txt`: Local file-based registry of sidebar commands.
- `build.sh`: Production build script (compiles release and replaces binary).
- `run.sh`: Convienence script for rebuild and launch.

## 4. Primary Workflows
- **Sidebar Tabs:** 
    - **COMMANDS:** Local commands from `commands.txt`.
    - **HISTORY:** Deduped shell history (~500 items).
    - **GISTS:** Fetched and cached Gists from GitHub.
- **GitHub Integration:**
    - Supports Gist-based scripts (with shebangs) and command lists.
    - Automatic detection of local cache modifications.
    - Interactive "Upload Modified Gist?" modal with mouse and keyboard support.
- **Live Updates:** Background monitoring reloads local and Gist command definitions when files are modified on disk.

## 5. UI & Interaction Patterns
- **Mouse Support:** Clickable sidebar items, tabs, scrollbars, and modal buttons.
- **Styling:** Custom status bars with hover effects and condition-based visibility (e.g., show Git info only if in a repo).
- **Terminal Pane:** Full 256-color support with custom ACS mapping for accurate rendering of tools like `nvtop` and `btop`.

## 6. Development Notes
- **ACS Patch:** Critical for rendering lines/grids. If box-drawing characters are broken, check `patch/vt100/src/perform.rs`.
- **Prompt Substitution:** Supports `<prompt:Label:Default>` syntax in commands for dynamic user input via the terminal.
- **Gist Cache:** Located in `~/.config/termbookman/gists/`. Filenames are sanitized (spaces to underscores).
